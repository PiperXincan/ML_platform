# ML Studio V10.3.0 交接包

本目录包含可独立运行的最新版前端、最新需求文档、最新开发文档和项目交接说明。

## 阅读顺序

1. `AI_HANDOFF.md`（面向大模型和新开发者的精简事实摘要）
2. `PROJECT_HANDOFF.md`（完整交接记录）
3. `机器学习训练平台前端开发文档.md`
4. `frontend-change-requirements-v7.md`（仅用于追溯 V7）
5. `index.html`、`app.js` 与 `app.css`

发生冲突时，以用户最新明确要求、`AI_HANDOFF.md`、`PROJECT_HANDOFF.md` 的 V10.2.2 结论和最新版开发文档为准。

## 运行方式

在本目录启动静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4173/`。

## 文件范围

- `index.html`：最新版页面入口，只加载一个脚本和一个样式文件。
- `app.js`：当前完整 JavaScript；保留历史分段，并在文件末尾激活最终生效的 V10.2 覆盖层。
- `app.css`：当前完整样式；保留历史分段，并在同一文件内追加 V10.2 样式。
- `PROJECT_HANDOFF.md`：项目目标、完成情况、关键决策、禁改项和已知缺口。
- `frontend-change-requirements-v7.md`：V7 历史需求，仅用于追溯。
- `机器学习训练平台前端开发文档.md`：最新完整开发文档 V10.2.2。
- `qa/smoke.test.js`：无第三方依赖的关键流程回归检查。

旧的 `v3.js`–`v8.js`、`v3.css`–`v8.css` 和 `v3-overrides.css` 已合并到 `app.js` 与 `app.css`，不再作为独立入口文件保留；需要追溯时使用 Git 历史。

## 版本信息

- 当前版本：`V10.3.0`
- V10.3.0 新增：智能选型入口。在模型训练页以“推荐入口”卡片提供固定参数多模型快速比较；支持二分类、多分类、回归和时序任务；按任务规则判断模型可用性并预推荐模型池；运行后按任务专属指标推荐模型，可从推荐或其他成功模型创建正式实验；保留历史记录、配置指纹与失效检查。
- V10.2.2 优化：修复日历特征开关并显示开关状态；将阈值动作明确为“自动筛选”并展示纳入/排除结果；时序模型增加常用参数、说明、范围校验和默认值恢复；快速自动调参展示推荐搜索范围，网格调参支持候选值编辑、组合数计算和 200 组上限。
- V10.2.1 修复：阻止旧分类/回归结果增强器在页面绑定阶段重写时序训练结果，确保只显示 MAE、RMSE、sMAPE、稳定性；训练结果和模型库最右操作列在表格内部横向滚动时保持固定吸附。
- V10.2.0 调整：时序上传数据只包含历史记录，未来外部特征改为在 API 请求时逐期提交；数据检查增加字段类型表和历史趋势图；时间列只能选择日期型字段；预测期数按频率与 3 轮回测历史共同限制；自动筛选仅使用历史缺失率和归一化方差，相关性仅提示；训练结果和模型库统一内部横向滚动、自动列宽和右侧固定操作列；保存结果后直接进入对应模型库详情。
- V10.1.1 修复：未来空目标不再被误判为数值 0；外部特征未来覆盖不足时必须先选择补全策略才能纳入；历史缺失值按模型采用训练窗口中位数/众数或原生缺失值处理；已保存模型的报告绑定不可变结果快照；ARIMAX 命名保持一致；时序 Mock API 对使用外部特征的方案采用完整未来特征请求，对基线预测和指数平滑继续只传预测期数。
- V10.1.0 新增：单序列时序预测支持一个目标列和多个外部特征；示例包含 365 期历史与 7 期未来计划数据；特征管理增加历史缺失率、归一化方差、时序相关性与最佳滞后、未来覆盖率及特征相关性热力图；ARIMA 在使用外部特征时展示为 ARIMAX，Prophet 与 LightGBM 同样可使用外部特征；训练结果与模型库表格统一自动列宽、内部横向滚动和固定操作列。
- V10.0.0 新增：独立“时序预测”项目，仅支持单序列日/周/月规则频率；增加时间列与数值目标校验、缺失时间/目标处理、3 轮扩展窗口回测、日历特征开关、五类基础预测模型、MAE/RMSE/sMAPE/稳定性结果、原生 SVG 预测报告、模型库快照及仅传预测期数的稳定 Mock API。
- V9.1.1 修复：训练结果无论是首次保存还是重复保存，都会进入对应模型实验的模型库详情；补齐状态式页面切换的 Hash 历史；从模型库进入报告后返回模型库；尚未训练时禁用训练结果和模型报告步骤。
- V9.1.0 调整：CSV 支持引号、字段内逗号与换行，增加 20MB 和 UTF-8 检查；模拟指标记录固定来源与生成时间；模型库保存训练快照；分类和回归统一安全修改目标列；数据预览改为每页 30 行；模型报告改为浏览器 PDF 导出；增加 Hash 路由、弹窗焦点管理、真实接口复制、API 删除确认、点击式表头筛选及 1024px 桌面适配。
- V9.0.11 调整：模型库指标对比表复用训练结果表的自动列宽策略；范围文字、操作按钮及按钮文字保持单行横向排列，操作列按实际按钮宽度展开。
- V9.0.10 修复与新增：多分类训练结果“显示指标”复用二分类交互并写入正确的多分类状态；模型库详情横向滚动限制在表格内部；训练结果和模型库指标列改为响应式自动宽度；模型报告曾增加浏览器本地保存演示，已在 V9.1.0 简化为直接导出 PDF。
- V9.0.9 新增：分类项目允许切换同子类型目标列；已有训练产物时改为“复制并修改目标列”，跨二分类/多分类时引导基于数据集新建项目。保存训练结果后进入对应实验的模型库详情，并可返回原训练结果。项目级和数据集级模型库筛选集成到表头并支持排序；训练结果保存、排名和参数方案列收窄。
- V9.0.8 修复：收紧多分类阈值业务范围并增加原生 min/max/step；筛选结果为零时不再提前修改阈值和特征状态。
- V9.0.7 调整：多分类特征管理的筛选阈值复用二分类布局，统一百分号、输入框、提示和按钮位置，并补齐 PSI 默认值 0.25。
- V9.0.6 调整：多分类报告开头新增完整指标总览，逐项对比训练集、验证集、差值与优化方向，并移除重复的核心指标卡片。
- V9.0.5 修复：多分类报告只参考二分类的视觉层级，使用独立 DOM 结构并阻止二分类 AUC、KS、阈值和混淆矩阵增强逻辑注入。
- V9.0.4 调整：多分类模型报告参照二分类的信息顺序增加训练集/验证集 Macro F1 对比，并将数据概览移至核心指标与各类别表现之间。
- V9.0.3 修复：多分类 Macro F1 指标卡不包含旧版二分类帮助节点时，报告绑定流程不再写入空 DOM 节点，避免出现 `Cannot set properties of null (setting 'title')`。
- V9.0.2 修复：模型报告兼容当前实验结果、模型库保存快照和旧 V4 多分类结果字段，无需重置本地状态。
- V9.0.1 修复：多分类阈值栏间距与实时标红校验、非数值方差说明、特征相关性热力图、训练结果进入模型报告。
- 本次升级：项目创建“二分类”改为“分类”；第一个有效数据集锁定二分类/多分类；补齐多分类数据检查、特征筛选、训练结果、报告、模型库标签和 Mock API。
