# ML Studio 前端项目交接摘要（V10.3.5）

> 面向后续大模型/开发者。本文总结项目目标、当前状态、关键决策、用户纠正过的方向、禁止项与未结问题。

---

## 1. 项目目标

- 面向机器学习初学者的零代码桌面 Web 演示平台。
- 前端单页面应用，无构建步骤、无真实后端、无真实训练。
- 当前覆盖：二分类、多分类（3–20 类）、普通回归、单序列时序预测。
- 用户按固定步骤完成：数据检查 → 特征准备 → 模型训练 → 训练结果/报告/模型库/API。
- 技术栈：原生 HTML + CSS + JavaScript，LocalStorage 持久化，Hash 路由。
- 当前版本：**V10.3.5**（缓存破坏参数 `app.js?v=10.3.5`、`app.css?v=10.3.5`）。

## 3. 当前已实现功能

### 3.1 通用能力
- 项目/数据集创建、CSV 上传、示例数据、20MB/UTF-8 检查。
- 固定 4 步流程：数据检查 → 特征准备 → 模型训练 → 结果查看。
- 模型库保存、比较、详情、报告、API 接入配置（全部前端模拟）。
- 弹窗、Hash 路由、LocalStorage 状态、PDF 导出。

### 3.2 分类/回归/多分类
- 二分类：逻辑回归、决策树、随机森林、KNN、LightGBM。
- 多分类（3–20 类）：沿用五个模型家族，逻辑回归按 Softmax 展示。
- 回归：线性回归、决策树、随机森林、KNN、LightGBM。
- 特征筛选：缺失率、归一化方差、PSI、特征相关性热力图。
- 训练结果：指标排序、Top 3/全部、保存到模型库、查看报告。

### 3.3 时序预测
- 单实体、单序列、单目标；支持多个外部特征。
- 模型：基线预测、指数平滑、ARIMA/ARIMAX、Prophet、LightGBM 时序。
- 固定 3 轮扩展窗口回测；上限按频率与历史长度共同限制。
- 特征准备：日历特征开关、外部特征筛选、相关性热力图。
- 调参：当前参数、快速自动调参、网格调参（≤200 组）。

### 3.4 智能选型（V10.3.0–V10.3.5）
- 模型选择页首位插入"智能选型"入口卡片。
- 按任务预推荐模型池；用户可调整池内模型。
- 固定参数逐个运行候选模型，按主指标排序并推荐。
- 结果页展示推荐模型 + 可展开对比表。
- 推荐模型卡片显示"★ 智能选型推荐"角标。
- 历史记录区、失效提示、配置变化检测。
- 从选型结果一键创建普通实验（命名规则与普通实验一致）。

## 4. 关键设计决策

1. **单文件覆盖层架构**
   - `app.js` 由 V3–V8 原始分段 + V9/V10/V10.3 覆盖层组成。
   - 同名函数**最后一次赋值生效**；修改前必须确认改的是最终版本。
   - 不要新增 `vX.js` 文件；后续改动直接编辑 `app.js`/`app.css`。

2. **版本隔离类名**
   - V10.2.2 之后的 DOM 类名/属性必须带版本后缀（如 `-v1022`、`-v1033`）。
   - 原因：V6 的 `enhanceExperimentPage` / `enhanceTuningPage` 对所有页面无差别执行 DOM 注入，不带版本后缀的类名会被旧增强器误改。

3. **智能选型推荐规则**
   - 推荐模型只标一张卡片（角标）。
   - 智能选型结果不进入模型库、不生成报告/API。
   - 创建实验走普通实验流程，实验名不带"智能选型"后缀。
   - 配置变化后旧记录标记失效，但不自动删除。

4. **时序相关性阈值**
   - 使用**绝对值**判断高相关（`Math.abs(score) >= threshold`），避免强负相关漏报。

5. **弹窗一致性**
   - 智能选型运行弹窗复用训练进度弹窗结构（`.training-overlay`、`.training-dialog`、`.training-minimize`、`.training-mini`）。

6. **全局表格居中**
   - V10.3.5 起所有 `table th, table td` 默认居中对齐。

## 6. 禁止/谨慎修改的部分

1. **不要引入真实后端、真实模型训练、登录权限、云端存储。**
2. **不要新增 JS/CSS 文件**，除非用户明确要求。
3. **不要修改 V10.2.2 及之前的核心逻辑**（如时序预测、特征筛选、训练结果计算）——只能做 UI 层包装或覆盖。
4. **不要轻易删除 V3–V8 的历史分段**，即使看起来冗余；它们是覆盖层的基础。
5. **不要恢复已删除的旧设计**：
   - 已删除的"滚动回测"措辞。
   - 已删除的多分类版本提示条。
   - 已废弃的"智能选型"实验名后缀。
   - 已移除的"恢复 0.80"按钮。
6. **智能选型结果不进入模型库/报告/API**——这是产品设计边界，不要突破。
7. **不要改 `modal()` 函数签名**；如需加弹窗 class，只能在调用后追加 class。
