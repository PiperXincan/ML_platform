# ML Studio 前端项目交接说明

> 面向后续开发者或大模型。优先遵循本文件列出的最终结论，不要根据旧版本需求自行恢复已取消的设计。

## 1. 项目定位

- 目标：面向机器学习初学者的零代码桌面 Web 平台，仅实现前端演示。
- 用户通过固定步骤和点击操作完成数据检查、特征准备、模型训练与结果查看。
- 当前任务范围：二分类、多分类（3–20 类）、普通回归。
- 当前不做：真实模型训练、真实后端、真实部署、登录权限、云端存储。
- 技术形态：原生 HTML、CSS、JavaScript，使用 `LocalStorage` 保存演示状态，无构建步骤。
- 仓库：[PiperXincan/ML_platform](https://github.com/PiperXincan/ML_platform)
- 当前主分支：`main`
- 整合前回退提交：`77d8730 fix: refine threshold feedback and library filters`

## 2. 事实来源优先级

发生冲突时按以下顺序判断：

1. 用户最新明确要求。
2. 本文件的 V9.0.0 最终结论。

### 3.1 V9.0.0 分类任务最终结论

- 创建项目只选择“分类”或“回归”。分类项目在第一个有效数据集点击“下一步：特征准备”并确认时，根据目标列锁定为二分类或多分类。
- 项目分类子类型锁定后，数据集仍可更换符合相同子类型的目标列。没有训练产物时原地修改并重置目标相关配置；已有训练结果、模型库快照或 API 配置时只能复制数据集后修改，原数据集保持不变。候选目标属于另一分类子类型时必须新建项目。
- 锁定后同一项目只能添加相同分类子类型的数据集；任务不同提示新建项目。删除项目内全部数据集后解除锁定。
- 2 类为二分类，3–20 类为多分类，超过 20 类不支持。目标空值不填充并排除训练；空值超过 10% 警告。
- 划分后每类必须在训练集和验证集各保留至少 1 条样本；80/20 至少 5 条，90/10 至少 10 条。
- 二分类保留正类且自动预选，允许修改；多分类不设置正类。多分类 3–10 类用环形占比图，11–20 类用横向条形图。
- 多分类沿用逻辑回归、决策树、随机森林、KNN、LGBM 五个模型家族，不增加算法；逻辑回归按 Softmax 多项逻辑回归展示。
- 多分类默认指标为 Macro F1 和 Accuracy，默认按验证集 Macro F1 降序；可选 Weighted F1、Macro Precision、Macro Recall、Log Loss 和 Macro F1 差值。
- 多分类特征筛选不使用 IV 和互信息。使用缺失率、归一化方差、PSI、特征相关性；方差仅对训练集 Min-Max 归一化后的数值特征计算，默认阈值 0.01。
- 多分类报告展示指标概览、每类 Precision/Recall/F1/Support、Top 3 混淆方向、变量重要性和数据概览。3–9 类展示完整混淆矩阵，10 类及以上不展示。
- 模型库全局索引只展示任务标签和管理信息，不跨项目比较指标；项目/数据集/实验详情使用该项目唯一任务类型的指标。
- 从训练结果保存模型后直接打开所属模型实验的模型库详情，保留来源上下文并显示“返回训练结果”；若来源实验被删除，回退到该数据集的实验列表并提示。
- 多分类 Mock API 返回 `prediction`、`confidence`、按概率降序的完整 `probabilities` 和 `mock`。二分类响应补充 `positiveClass` 与 `threshold`。
- V9 使用 `mlStudioV4` 和 `schemaVersion: 4`，不读取、转换或删除旧的 `mlStudioV3` 测试状态。

## 4. 已完成页面与组件

### 4.1 项目与数据集

- 项目列表、项目创建、项目详情、创建时间展示。
- 项目可直接创建；目标列不在项目创建时选择。
- 添加数据集时选择 CSV 或与项目任务匹配的示例数据。
- 提供二分类、多分类和回归示例；多分类内置“客户价值等级预测”（4 类）和“贷款风险等级预测”（3 类），覆盖数值、类别、布尔、缺失、日期、ID、低方差、高相关和不平衡场景。
- 数据集卡片有两个独立入口：“进入数据集”和“模型实验（数量）”。
- 数据集悬浮弹窗包含数据概览和数据预览。
- 数据概览最多前 50 个特征，每页 10 个；数据预览有表头和分页。
- CSV 字段类型检查、列内类型一致性展示、目标列设置、不可训练字段标记。
- 项目、数据集和模型实验支持删除及级联清理。

### 4.2 特征准备

- 固定流程：`数据检查 → 特征准备 → 模型训练 → 训练结果`。
- 特征准备包含训练集/验证集划分和特征管理。
- 默认比例 `80% / 20%`，保留其他预设比例；二分类和多分类均使用分层划分。
- 自动筛选与“推荐阈值”是两个不同功能。
- 自动筛选使用系统固定推荐规则，直接更新特征列表。
- 推荐阈值只恢复输入框数字，用户仍可修改，再点击“确定修改”。
- 默认筛选：缺失率不高于 90%；二分类 IV 不低于 0.01；多分类数值特征归一化方差不低于 0.01；另有 PSI、低方差、目标相关性规则。
- 相关性矩阵使用热力图；阈值和相关性自动处理都位于热力图区块。
- 高相关处理先展示动态预览，确认后排除，且允许用户重新纳入。
- IV、PSI、低方差和目标相关性有简短说明；缺失率和特征间相关性不增加解释区间。

### 4.3 模型训练与调参

- 分类模型：逻辑回归、决策树、随机森林、KNN、LGBM。
- 回归模型：线性回归、回归树、随机森林回归、LGBM 回归。
- 模型只展示适用的参数和调参方式。
- 常用参数精简展示，并提供简短解释和推荐值。
- 高级参数默认折叠；枚举参数使用下拉框，例如划分标准、求解器、最大特征数。
- 网格调参使用预设候选值，但高级设置允许修改，并实时计算组合数量。
- 快速自动调参不展示算法名称、尝试次数或随机种子，只保留最佳三组结果。
- 训练进度为不可通过遮罩关闭的居中弹窗，支持最小化和取消。
- 成功实验锁定，不能再次训练；需要修改时复制为新模型实验。
- 已完成实验在列表和详情中都可直接进入训练结果。

### 4.4 训练结果与报告

- 结果默认展示 Top 3，可展开全部结果。
- 默认仅勾选当前排序指标下第一名，用户可以多选其他结果。
- 结果可按训练集或验证集指标排序，默认验证集。
- 二分类、多分类和回归的“显示指标”使用各自独立状态；复选项点击后立即更新，面板保持展开，至少保留一项，取消当前排序指标后自动切换到剩余第一项。
- 分类指标：AUC、KS、F1、准确率、精确率、召回率、训练/验证差值。
- 回归指标：RMSE、MAE、R²、训练/验证差值。
- 模型报告是训练结果下级详情页，不是第五个流程步骤。
- 分类报告包含 ROC、KS、Gain Table、验证集混淆矩阵及 Accuracy、Precision、Recall、F1 计算。
- 报告展示训练集指标、验证集指标和差值。
- 变量重要性明确标注计算方式，不跨模型直接比较分数。

### 4.5 模型库与 API 演示

- 模型库是全局一级页面，可查看全部项目。
- 支持项目、数据集、模型类型筛选和指标排序。
- 同一实验保存多组结果时，每组形成独立模型库记录，但不创建新实验。
- 保存后先写入本地模型库，再跳转，确保新增结果立即可见。
- 项目级详情在数据集、模型实验、模型类型表头提供联动筛选；数据集级详情在模型实验、模型类型表头提供联动筛选。筛选区不单独占据表格上方空间，范围列、参数方案、指标和创建时间均可由表头排序。
- 模型库详情增加指标列后只在表格内部横向滚动，不允许撑宽整个页面；训练结果和模型库的指标列按内容及可用空间自动分配，达到最小可读宽度后使用内部滚动。
- 模型报告保存当前仅用于前端演示：按“实验 + 参数结果”在浏览器本地记录报告名称、保存时间、任务信息和结果快照，不生成真实 PDF、不上传服务器；重复保存更新同一记录。
- 模型库展示项目、数据集、实验、模型类型、参数、训练/验证指标和创建时间。
- 重复保存会阻止新增，并提示结果已保存。
- API 服务属于模型部署概念，但当前只提供前端模拟接入配置，不是真实部署。

### 4.6 导航与状态

- 一级页面不显示返回按钮。
- 所有二级页面使用统一底部固定操作栏：返回在左，下一步或主要操作在右。
- 下一步按钮必须位于右下方或底部吸附区，不能移动到页面顶部。
- 返回时保留已填写配置、划分比例和筛选状态。
- 演示数据和操作状态使用 `LocalStorage` 保存。

## 5. 已确认的关键设计决策

- 彻底取消机器学习流程画布，不做节点拖拽、连线、缩放或自由编排。
- 用户通过固定向导式流程操作；“零代码”不等于必须使用画布。
- 项目创建不弹出目标列选择；创建数据集时再选择目标列。
- 字段类型检查属于数据集模块；自动排除属于特征管理。
- 不可训练字段必须明确标注“不可用于训练”，而不是弱提示“建议排除”。
- 全平台使用验证集，不使用“测试集”命名，也不使用交叉验证。
- 缺失值填充、编码和标准化参数只根据训练集计算，再应用到验证集，防止数据泄漏。
- 特征间相关系数绝对值越高，冗余风险越大；不是绝对值越低就一定越好。
- 类别缺失值的“不处理”和“作为独立类别”含义不同；当前允许模型采用适合自身的默认方式。
- 一个成功实验不能重复训练；修改配置必须复制为新模型实验。
- 快速自动调参只保留最佳三组；结果页默认展示 Top 3，但只默认勾选当前第一名。
- 模型库保存的是实验下的参数结果，不把每组参数误称为新实验。

## 7. 禁止修改或恢复的内容

- 禁止恢复自由画布、拖拽建模流程、节点和连线。
- 禁止把目标列选择移动到项目创建流程。

- 禁止按完整数据集计算填充、编码和标准化参数。
- 禁止展示随机种子、自动调参算法名称或尝试次数。
- 禁止移动底部固定返回/下一步操作栏。
- 禁止把模型报告重新加入主步骤条。
- 禁止默认勾选前三名结果。
- 禁止把同一实验的多组参数结果创建为多个实验。
- 禁止新增真实 API、账号权限、云存储或其他未确认模块。
- 禁止删除旧版本文件或重构版本叠加架构，除非用户明确批准。

## 8. 当前问题与已知缺口

当前没有阻塞前端继续评审的问题，页面可直接运行。以下是已知限制，不能在未确认时擅自扩展：

- 所有训练、指标、统计数据和 API 均为 Mock，不连接真实机器学习服务。
- CSV、示例数据预览和分页主要用于交互演示；示例预览行数有限，分页可能复用 Mock 行。
- 训练流程目前只有成功和取消演示，尚未提供可主动触发的失败场景；需求文档要求失败时展示原因和返回修改入口。
- 混淆矩阵 Mock 数据通常不会出现分母为 0；开发文档规定真实数据下应显示 `—`，不能显示 `NaN`。
- 模型库目前通过“查看训练结果”再进入模型报告，没有单独的直接报告按钮。
- 高级参数控件以界面演示为主，并非所有输入都会形成真实训练请求。
- V3–V7 采用全局函数覆盖方式，长期维护成本较高，但当前不能在无授权时重构。

## 9. 运行与验证

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4173/`。

最近一次回归已验证：

- 已完成实验可直接进入训练结果。
- 高级参数中的划分标准使用下拉框，并显示推荐值。
- 分类报告显示验证集混淆矩阵和计算指标。
- 保存结果后模型库立即出现记录。
- 重复保存不会创建重复记录。
- 底部操作栏为固定定位。
- 浏览器控制台无错误。

## 10. 后续修改流程

1. 先阅读 `frontend-change-requirements-v7.md` 和本文件。
2. 对照 `机器学习训练平台前端开发文档.md` 判断是否需要同步更新文档。
3. 只修改用户指定范围；脚本统一修改 `app.js`，样式统一修改 `app.css`，不要再创建按版本递增的脚本或样式文件。
4. 回归分类和回归两条主流程，特别检查底部按钮、训练弹窗、结果保存和模型库。
5. 修改完成后执行 JavaScript 语法检查和浏览器控制台检查。
