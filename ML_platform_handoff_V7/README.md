# ML Studio V9.0.9 交接包

本目录包含可独立运行的最新版前端、最新需求文档、最新开发文档和项目交接说明。

## 阅读顺序

1. `PROJECT_HANDOFF.md`
2. `机器学习训练平台前端开发文档.md`
3. `frontend-change-requirements-v7.md`（仅用于追溯 V7）
4. `index.html`、`app.js` 与 `app.css`

发生冲突时，以用户最新要求、`PROJECT_HANDOFF.md` 的 V9 结论和最新版开发文档为准。

## 运行方式

在本目录启动静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4173/`。

## 文件范围

- `index.html`：最新版页面入口，只加载一个脚本和一个样式文件。
- `app.js`：当前完整 JavaScript；保留 V3–V8 历史分段，并在同一文件内增加最终生效的 V9 覆盖层。
- `app.css`：当前完整样式；保留 V3–V8 历史分段，并在同一文件内追加 V9 样式。
- `PROJECT_HANDOFF.md`：项目目标、完成情况、关键决策、禁改项和已知缺口。
- `frontend-change-requirements-v7.md`：V7 历史需求，仅用于追溯。
- `机器学习训练平台前端开发文档.md`：最新完整开发文档 V9.0.9。

旧的 `v3.js`–`v8.js`、`v3.css`–`v8.css` 和 `v3-overrides.css` 已合并到 `app.js` 与 `app.css`，不再作为独立入口文件保留；需要追溯时使用 Git 历史。

## 版本信息

- 当前版本：`V9.0.9`
- V9.0.9 新增：分类项目允许切换同子类型目标列；已有训练产物时改为“复制并修改目标列”，跨二分类/多分类时引导基于数据集新建项目。保存训练结果后进入对应实验的模型库详情，并可返回原训练结果。项目级和数据集级模型库筛选集成到表头并支持排序；训练结果保存、排名和参数方案列收窄。
- V9.0.8 修复：收紧多分类阈值业务范围并增加原生 min/max/step；筛选结果为零时不再提前修改阈值和特征状态。
- V9.0.7 调整：多分类特征管理的筛选阈值复用二分类布局，统一百分号、输入框、提示和按钮位置，并补齐 PSI 默认值 0.25。
- V9.0.6 调整：多分类报告开头新增完整指标总览，逐项对比训练集、验证集、差值与优化方向，并移除重复的核心指标卡片。
- V9.0.5 修复：多分类报告只参考二分类的视觉层级，使用独立 DOM 结构并阻止二分类 AUC、KS、阈值和混淆矩阵增强逻辑注入。
- V9.0.4 调整：多分类模型报告参照二分类的信息顺序增加训练集/验证集 Macro F1 对比，并将数据概览移至核心指标与各类别表现之间。
- V9.0.3 修复：多分类 Macro F1 指标卡不包含旧版二分类帮助节点时，报告绑定流程不再写入空 DOM 节点，避免出现 `Cannot set properties of null (setting 'title')`。
- V9.0.2 修复：模型报告兼容当前实验结果、模型库保存快照和旧 V4 多分类结果字段，无需重置本地状态。
- V9.0.1 修复：多分类阈值栏间距与实时标红校验、非数值方差说明、特征相关性热力图、训练结果进入模型报告。
- 本次升级：项目创建“二分类”改为“分类”；第一个有效数据集锁定二分类/多分类；补齐多分类数据检查、特征筛选、训练结果、报告、模型库标签和 Mock API。
- 本地状态键：`mlStudioV4`，`schemaVersion: 4`；不迁移也不删除旧的 `mlStudioV3` 测试数据。
