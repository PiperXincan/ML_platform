| 项目 | 内容 |
| --- | --- |
| 产品名称 | ML Studio 一体化机器学习训练平台 |
| 当前版本 | 前端 V10.2.2 |
| 目标用户 | 了解少量机器学习知识、希望通过零代码训练模型的初学者 |
| 支持任务 | 二分类、多分类（3–20 类）、普通回归、单序列时序预测 |

V10.2.0 继续使用原生 JavaScript 与 CSS，不使用 React。模拟训练结果允许完整展示流程，但必须记录结果来源与固定生成时间，同一次训练在训练结果、模型库、报告和 API 中保持一致。时序预测保持单实体、单序列、单目标边界，并支持多个外部特征；上传文件只包含历史数据，未来外部特征在 API 请求时提供。分类和回归既有规则不变。

V10.2.1 明确隔离分类/回归训练结果增强逻辑：时序训练结果仅允许 MAE、RMSE、sMAPE、稳定性四项指标。结果表与模型库指标表在自身容器内横向滚动，最右操作列始终固定吸附。

V10.2.2 修复时序日历特征开关并明确显示状态；阈值筛选使用显式“自动筛选”动作和结果反馈。时序模型使用独立参数组件，常用参数始终展开并提供说明、范围校验和默认值恢复；快速自动调参展示推荐范围，网格调参支持候选值编辑、组合数计算和 200 组上限，不增加贝叶斯调参。

## 2. 产品目标

1. 通过项目制管理数据集、模型实验和参数结果。
2. 让初学者通过固定步骤完成数据检查、特征工程、模型训练和结果理解。
3. 在关键指标旁提供通俗解释、参考范围和优化方向。
4. 降低错误配置概率，不向用户暴露不适用于当前任务或模型的选项。
5. 为未来接入真实数据分析、训练、模型服务和 API 网关预留服务层边界。

## 3. MVP 边界

### 3.1 当前实现

- 项目、数据集、模型实验和参数结果的本地管理。
- CSV 类型检查、数据预览和目标列配置。
- 特征准备，以及模型级缺失值处理、标准化和参数配置。
- 二分类、多分类、回归与单序列时序预测的模型选择、模拟训练和模拟调参。

- 登录、权限、团队协作、计费、云端存储和数据集版本管理。
- Excel、数据库和云端数据源。
- 真实模型部署、API 密钥、调用额度、调用统计和服务启停。
- 移动端和平板适配。

## 4. 已确认的产品规则

### 4.1 项目层级

平台使用以下层级：

`项目 → 数据集 → 模型实验 → 参数结果`

- 一个项目可以包含多个数据集。
- 一个数据集可以包含多个模型实验。
- 一个模型实验对应一个模型类型和多组参数结果。
- 同一模型类型允许创建多个实验。

### 4.2 任务类型与项目锁定

- 创建项目时选择“分类”“回归”或“时序预测”，并自动记录创建时间。
- 分类项目初始为“待识别”。第一个有效数据集在点击“下一步：特征准备”时，根据目标列有效类别数弹出确认：2 类锁定为二分类，3–20 类锁定为多分类。
- 锁定后同一项目只能添加相同分类子类型的数据集；不匹配时阻止继续并提示新建项目。
- 项目没有数据集时保持待识别；删除全部数据集后解除分类子类型锁定。
- 分类子类型锁定后仍允许修改目标列，但候选列必须通过 2–20 类、最小样本数及项目子类型一致性校验。是否允许原地修改由该数据集是否已有训练产物决定，与项目下数据集数量无关。
- 分类项目只展示既有五个分类模型家族，回归项目只展示回归模型，时序项目只展示五个预测模型家族。

### 4.3 目标列

- 目标列属于数据集，一个数据集只设置一个目标列。
- 同一数据集下所有模型实验共享目标列。
- 数据集没有训练结果、模型库快照或 API 配置时，可原地修改为相同分类子类型的目标列；修改后重新计算类别、缺失数和正类，重置特征配置与实验草稿，原目标列默认排除以避免泄漏。
- 数据集已有任一训练产物时，目标列下拉框锁定，只提供“复制并修改目标列”。副本保留原始数据和字段统计，但不继承模型实验、训练结果、模型库记录或 API 配置；原数据集完全不变。
- 候选目标列识别为另一分类子类型时，不允许修改或复制到当前项目，页面提供“基于该数据集新建项目”，并在新项目中锁定正确的二分类或多分类子类型。
- 需要预测其他目标时，用户应创建新数据集。
- 类别数只统计目标列非空值；目标空值行自动排除训练且禁止填充，空值比例超过 10% 时警告。
- 每个类别必须能在训练集和验证集各保留至少 1 条样本：80/20 划分每类至少 5 条，90/10 划分每类至少 10 条。
- 最大类 / 最小类样本比达到 3 时警告，达到 10 时严重警告；当前不自动重采样。
- 二分类必须有内部正类定义，系统优先匹配“是、1、true、流失、违约、阳性”，否则预选少数类；用户可直接修改。多分类不设置正类。

### 4.4 多分类指标、特征与报告

- 多分类沿用逻辑回归、决策树、随机森林、KNN、LGBM；逻辑回归展示为 Softmax 多项逻辑回归，本轮不增加新算法或真实求解器逻辑。
- 默认指标为 Macro F1 与 Accuracy，训练结果默认按验证集 Macro F1 降序。可选 Weighted F1、Macro Precision、Macro Recall、Log Loss 和 Macro F1 训练/验证差值；不展示 AUC、KS、Micro F1。
- 多分类不使用 IV 与互信息。自动筛选规则为缺失率 ≤ 90%、数值特征 Min-Max 归一化方差 ≥ 0.01、PSI ≤ 0.25；类别和布尔特征跳过方差判断，另保留特征相关性处理。
- 多分类筛选阈值与二分类复用同一面板结构、输入框宽度、单位位置、帮助提示和底部按钮布局；首次进入或旧状态缺少字段时默认显示缺失率 90%、归一化方差 0.01、PSI 0.25，已保存且处于合法范围的修改继续保留。多分类业务范围为缺失率 `0–99%`、归一化方差 `0–0.25`、PSI `0.05–0.8`，步长依次为 `1`、`0.01`、`0.01`。
- 非数值特征在方差列显示“不适用”，表示不计算数值方差，并不表示跳过或排除该特征。阈值输入超过业务范围时与二分类一致：输入框实时标红并显示行内错误。
- 多分类特征管理页必须展示训练集数值特征相关性热力图，并复用相关性阈值修改和高相关特征处理流程。
- 类别占比图：3–10 类使用环形图，11–20 类使用横向条形图。报告混淆矩阵：3–9 类展示完整矩阵，10 类及以上不展示。
- 报告开头使用独立的“指标总览”表，逐项展示 Macro F1、准确率、Weighted F1、Macro Precision、Macro Recall、Log Loss 的训练集值、验证集值、绝对差值和优化方向；验证集列突出显示，指标名称提供简短说明。后续依次展示总体结论、数据概览、每类 Precision/Recall/F1/Support、Top 3 类别混淆方向、变量重要性和指标说明；不重复展示核心指标卡片。多分类不展示二分类阈值、TP/TN/FP/FN、ROC、KS 与 Gain。
- 模型库全局索引不展示跨任务指标，只显示任务标签；项目、数据集和模型实验详情使用项目唯一分类子类型对应的指标。
- 多分类 Mock API 响应包含 `prediction`、`confidence`、按概率降序排列的完整 `probabilities` 数组和 `mock`。
- 模型报告入口必须兼容当前实验结果和模型库保存快照；旧 V4 多分类结果缺少新指标字段时，在前端补齐稳定展示值，不要求用户重置本地数据。

### 4.5 单序列时序预测

- 任务边界：只支持一个实体的一条规则时间序列，时间频率限定为日、周、月；不支持门店 × 商品等多实体联合预测、不规则事件流、时序分类和异常检测。
- 数据结构：一个日期型时间列、一个数值目标列，可包含多个数值、类别或布尔外部特征。上传内容全部属于历史区间，不接收未来目标或未来特征。系统自动推断频率，用户必须确认；手动把字段改为日期类型时必须整列解析通过。
- 数据检查：提供字段类型表、缺失率、唯一值、训练角色和历史目标趋势图。无效日期、频率桶重复、非数值目标、历史时间缺口和历史长度不足直接阻断；最低有效历史点为日 60、周 30、月 24。历史时间缺口不自动填补，用户必须修复源数据并重新上传；仅原始顺序未排序时自动排序并提示。
- 共享配置：频率、预测期数、3 轮扩展窗口回测、缺失策略和日历特征开关属于数据集。模型类型、模型参数和调参方式属于实验。
- 日历特征：默认开启。日频生成星期、月份、季度、是否周末；周频生成周序号、月份、季度；月频生成月份、季度。
- 预测期数：上限为 `min(频率固定上限, floor((有效历史点 - 最低训练点) / 3))`；日、周、月固定上限分别为 90、26、12。非法值实时标红、显示行内范围提示且不能生效。
- 上传特征筛选：自动筛选只使用首个回测训练窗口中的历史缺失率（默认上限 90%）和归一化方差（默认下限 0.01）。时序相关性与最佳滞后只作参考，不参与自动剔除。数值外部特征相关性热力图始终展开，默认绝对相关性 0.8 预警，允许输入范围 0.50–0.99；预警不自动删除字段。
- 筛选交互：恢复推荐阈值只更新输入值，点击“自动筛选”后才批量纳入或排除，并展示数量结果；用户随后仍可手动调整。日历特征开关显示“已开启/已关闭”并列出实际生成字段。
- 历史缺失处理：ARIMAX 与 Prophet 的数值外部特征使用每轮训练窗口中位数填充，类别外部特征使用每轮训练窗口众数填充；LightGBM 保留缺失值并增加缺失指示特征。所有统计量只从当前回测轮次的训练窗口计算，避免泄漏验证期信息。
- 模型专属处理：目标滞后、滚动统计、趋势、差分和季节性由训练阶段按模型自动处理，不在共享特征管理页逐项配置。
- 结果排序：用户不选择是否回测，平台固定执行 3 轮扩展窗口回测；训练结果默认按三轮平均 MAE 升序，另展示 RMSE、sMAPE 和三轮 MAE 标准差形式的稳定性。
- 模型使用：基线预测与指数平滑仅使用目标历史；ARIMA 在纳入外部特征时显示为 ARIMAX；Prophet 和 LightGBM 可使用外部特征。报告与训练快照记录实际使用或忽略的外部特征。
- 时序参数与调参：基线预测自动比较五种方案；指数平滑展示趋势、季节性、周期和阻尼；ARIMA/ARIMAX 展示 p/d/q 及季节项；Prophet 展示趋势灵活度、季节性强度和模式；LightGBM 展示树数量、学习率、深度、叶子数和最大滞后。非基线模型支持当前参数、快速自动调参和网格调参，候选组合最多 200 组。
- 模型报告：开头展示四项指标总览，其后为数据与配置、最近一轮回测、误差分析、外部特征使用情况、模型说明和配置快照。上传数据不含未来特征，因此使用外部特征的方案在 API 请求前不编造未来预测图；回测图继续使用原生 SVG。
- 结果保存：保存后直接进入对应实验的模型库详情；保存快照包含时间列、目标列、频率、预测期数、回测轮次、日历特征、外部特征、筛选阈值、模型和参数。模型库打开报告时只读取该不可变快照，不受当前实验后来修改影响。
- API Mock：配置绑定具体已保存方案。基线预测和指数平滑请求只接收正整数 `horizon`；使用外部特征的 ARIMAX、Prophet 与 LightGBM 请求还必须提供与预测日期一一对应的 `futureFeatures`。页面以可编辑表格展示并校验每期特征，响应返回未来日期、预测值、80% 区间和 95% 区间；相同请求返回稳定结果，修改未来特征后响应同步变化。
- 内置示例：`商品每日销量示例` 包含 365 期完整历史数据；一个销量目标和商品价格、是否促销、广告费用、节假日类型四个外部字段，默认预测未来 7 天并开启日历特征。

### 4.6 本地状态

- V10 继续使用 LocalStorage 键 `mlStudioV4`，采用增量默认值兼容现有测试状态，不执行复杂迁移。
- 现有数据均为测试示例，不迁移、不读取、不转换也不删除旧键 `mlStudioV3`。
- 内置两个多分类示例：“客户价值等级预测”（4 类）与“贷款风险等级预测”（3 类）。

## 5. 信息架构

### 5.1 全局导航

| 一级入口 | 主要内容 |
| --- | --- |
| 首页 | 产品引导、最近项目、创建项目 |
| 项目 | 项目列表、数据集卡片、项目详情 |
| 模型库 | 可筛选的模型实验列表、方案指标详情和 API 入口 |

项目内部使用二级导航：

`项目概览 → 数据集 → 模型实验`

数据集内部使用固定步骤条：

`数据检查 → 特征准备 → 模型训练 → 训练结果`

- 侧边栏只保留首页、项目、模型库和初学者模式提示，不展示项目快捷列表。
- 页面顶端的“当前项目”只在项目内部页面展示；首页、项目列表、全局模型库和 API 服务等全局页面不展示当前项目。即使模型库已筛选到某个项目，它仍属于全局页面，不在顶栏展示当前项目。
- 二级页面按实际去向显示返回按钮；一级页面不显示“返回上一步”。
- 流程页面使用底部吸附操作栏：返回按钮固定在左侧，下一步或主要操作固定在右侧，页面未滚动到底部时也保持可见。
- 项目详情、模型实验列表、报告详情和 API 说明等二级页面同样使用该底部操作栏，避免返回按钮位置变化。
- 模型报告不属于流程步骤，是训练结果的下级详情页。

### 5.2 步骤状态

| 状态 | 说明 |
| --- | --- |
| 未开始 | 尚未进入或缺少前置配置 |
| 进行中 | 已进入但配置尚未完成 |
| 已完成 | 当前配置有效，可以进入下一步 |
| 历史结果 | 上游配置已变化，旧结果仅供查看 |

修改字段类型、数据划分或共享特征集合后，已有成功实验标记为“历史结果”，不删除旧结果，也不允许再次训练。目标列修改遵循 4.3 的单独安全规则：已有训练产物时必须创建数据集副本，不能直接修改原数据集。

## 6. 页面设计

### 6.1 首页

- 展示产品定位和“创建项目”主按钮。
- “当前工作区”统计项目总数、数据集总数和模型实验总数。
- 展示最近项目卡片，包括项目名称、任务类型、数据集数量、模型实验数量和更新时间。
- 无项目时提供二分类和回归示例入口。
- 当前工作区没有项目时，在页面空白区展示“创建项目”主按钮。

### 6.2 创建项目

只包含以下字段：

| 字段 | 规则 |
| --- | --- |
| 项目名称 | 必填，本地项目内唯一 |
| 任务类型 | 分类或回归，必填；分类子类型由首个有效数据集锁定 |
| 创建时间 | 系统生成，不可编辑 |

创建成功后进入项目详情空状态，引导用户上传第一个数据集。

- 项目列表卡片右上角提供“三点菜单 → 重命名项目 / 删除项目”，不直接常驻红色删除按钮；项目详情页标题区也提供“重命名项目”。
- 项目重命名要求名称非空且不得与其他项目重名，确认后立即更新首页、侧边栏、项目列表和模型库中的项目名称。
- 点击卡片菜单不会触发进入项目；删除仍使用统一二次确认，并明确提示级联删除数据集、模型实验、保存结果和 API 配置。
- 删除后停留在项目列表；删除最后一个项目后直接展示项目空状态。
- 项目内没有数据集时，在数据集空白区展示“添加数据集”主按钮；空状态已有主入口时，不在页面标题区重复展示同一入口。

### 6.3 数据集卡片交互

- 数据集卡片不显示悬浮窗；数据概览和数据预览统一在进入数据集后的页面查看。
- 除删除悬浮窗外，卡片已有信息、按钮、重命名菜单和进入流程保持不变。

### 6.4 项目详情

- 顶部显示项目名称、任务类型、创建时间和项目状态。
- 数据集列表展示名称、上传时间、行列数、目标列、模型实验数和流程状态。
- 每个数据集提供“进入数据集”和“模型实验（数量）”两个按钮，卡片主体不承担隐含跳转。
- 数据集列表提供轻量“三点菜单 → 重命名数据集”，数据检查页标题区也提供“重命名数据集”。同一项目内数据集名称不得重复。
- 提供“上传数据集”和“查看本项目模型”按钮。
- 尚未上传数据时允许修改任务类型；上传后该操作隐藏。

## 7. 数据集模块

### 7.1 数据集创建

- 点击“上传数据集”后打开统一弹窗，提供“上传 CSV”和“使用示例数据”两个入口。
- 示例数据只展示符合当前项目任务类型的数据集；每种任务固定提供两个示例。
- 二分类示例为“客户流失预测”和“贷款违约预测”；回归示例为“住宅价格预测”和“二手车价格预测”。示例包含数值、类别、日期、疑似 ID、缺失值和目标列，用于测试类型检查、特征筛选和相关性功能。
- 默认使用 CSV 文件名作为数据集名称，允许修改。
- 同一项目内名称不得重复。
- 自动记录上传时间、行数和列数。
- 预览最多读取前 150 行，不代表完整数据量。
- 读取字段后由用户选择目标列；二分类同时选择正类。
- 创建项目时不选择目标列，项目允许在没有数据集的情况下直接创建。
- CSV 或示例数据创建成功后返回当前项目的数据集列表，不直接进入数据检查页；用户再通过“进入数据集”开始检查。

### 7.2 CSV 检查

- 第一版正式支持 UTF-8 CSV，文件上限为 20MB。
- 支持标准引号、字段内逗号、字段内换行和双引号转义。
- 文件必须包含表头和至少一行数据。
- 表头不能为空、不能重复。
- 行列数不一致时阻止继续，并显示错误行号。
- 每列检查数值、日期、布尔、类别和文本类型的一致性。
- 类型混合时展示异常数量、异常示例和修正入口。

### 7.3 字段类型检查

字段类型检查放在数据集模块，表格字段包括：

| 字段 | 说明 |
| --- | --- |
| 字段名称 | CSV 表头名称 |
| 推断类型 | 数值、类别、日期、布尔或文本 |
| 用户确认类型 | 可手动修正 |
| 非空 / 缺失 | 数据完整性概览 |
| 唯一值数量 | 辅助识别类别、ID 和自由文本 |
| 一致性 | 一致或存在异常 |
| 训练可用性 | 可用于训练或不可用于训练 |
| 原因 | 日期、自由文本、疑似 ID 或类型异常等原因 |

### 7.4 不可训练字段

- 类别型字符串可以用于训练，并在特征工程中编码。
- 自由文本、疑似 ID 和原始日期字段标注“不可用于训练”。
- 不使用“建议排除”措辞。
- 数据集模块负责识别和解释，不提供排除开关。
- 目标列不受该规则限制。

### 7.5 目标列设置

- 用户完成字段检查后选择目标列。
- 二分类目标列必须具有两个有效类别，并选择正类。
- 回归目标列必须为数值类型。
- 不符合项目任务类型时阻止进入特征工程，并给出修正建议。
- 数据集没有任何模型实验时允许原地修改有效目标列；只要已有实验、模型快照或 API 配置，就必须复制数据集后修改，原数据集保持不变。
- 分类副本必须保持项目当前二分类或多分类子类型；回归副本只允许数值型目标列。

## 8. 特征准备与模型预处理

### 8.1 特征准备

“特征准备”页面只包含训练集 / 验证集划分和特征管理，并由同一数据集下所有模型实验共享。从数据检查进入时始终先显示划分页面，并保留用户已选择的比例。

页面内部顺序固定为：

1. 选择 70%/30%、75%/25%、80%/20% 或 90%/10%，默认 80%/20%。
2. 平台内部使用固定划分规则完成训练集 / 验证集划分，前端不展示随机种子。
3. 只使用训练集计算特征筛选指标。
4. 将最终特征集合应用到验证集。

二分类默认使用分层划分，保证训练集和验证集的类别比例接近。数据检查页展示类别分布和正类占比；类别明显不平衡时提示准确率不能单独用于判断模型效果。

### 8.2 特征筛选指标

| 任务 | 展示指标 |
| --- | --- |
| 二分类 | 缺失率、IV、PSI、特征间相关性 |
| 回归 | 缺失率、低方差、目标相关性、PSI、特征间相关性 |

- 回归任务不展示 IV，也不应用 `IV ≥ 0.01` 规则。
- 二分类默认缺失率阈值 90%、IV 阈值 0.01、PSI 上限 0.25、相关系数绝对值阈值 0.8，四项阈值均可调整并参与自动筛选或预警。
- 回归自动筛选同时应用缺失率、低方差、目标相关性和 PSI：数值特征需满足 `方差 ≥ 低方差阈值` 且 `|目标相关性| ≥ 目标相关性下限`；非数值特征不套用这两项数值规则。
- “自动筛选”位于特征管理卡片右上角，始终使用系统内置推荐规则并直接更新纳入开关。
- 筛选栏提供“推荐阈值”和“确定修改”：前者只恢复推荐数字，后者应用用户当前填写的阈值并更新纳入开关。分类与回归任务的操作区均固定在模块内部右下角，“确定修改”位于最右侧。
- 阈值输入框正常状态下不常驻展示允许范围。用户输入空值或超出业务范围时，才在对应输入框下方显示提示并标红；用户把数值改回正常范围后，红框和提示必须立即消失，无需点击“确定修改”。点击“确定修改”时再次校验，校验失败时保留原有阈值和特征开关。业务范围仍为：缺失率上限 `0–99%`、IV 下限 `0–0.8`、PSI 上限 `0.05–0.8`、低方差阈值 `0–0.5`、目标相关性下限 `0–0.95`。
- 多分类使用归一化方差，因此其方差上限单独限制为 `0.25`。任何阈值组合若会排除全部可训练特征，必须先提示并取消提交，不得修改内存状态、特征开关或 LocalStorage。
- 数值特征相关性使用热力图展示，在 `|r| ≥ 0.8` 时预警，默认不自动排除。
- 相关性阈值位于热力图区块，正常状态下不显示范围；输入空值或超出 `0.3–0.99` 时才显示提示并阻止确认。修改后点击蓝色主按钮“确定修改”才更新预警。
- 点击“自动处理高相关特征”后先展示处理预览，不直接修改特征开关。预览顶部明确列出最终保留字段、建议排除字段及各自数量。
- 预览提供“查看详情”，展开后按保留字段分组展示“保留字段、排除字段、相关系数、推荐理由”。同一保留字段只展示一次，每个排除字段只归入一个最终保留字段；多个排除字段分别标明对应相关系数和理由。
- 自动处理优先保留缺失率更低、筛选指标更优且 PSI 更稳定的字段；二分类可参考 IV，多分类参考归一化方差。只有点击“确认处理”后才应用排除结果；没有达到当前阈值的高相关字段时只提供关闭操作。
- 被自动排除的特征允许手动重新纳入，并继续显示高相关性提醒。
- IV、PSI、低方差和目标相关性提供悬浮解释、数值方向和参考范围；缺失率和特征间相关性不增加解释区间。
- 筛选栏下方提供“查看指标说明”折叠区。
- 所有指标标注“根据训练集计算”。
- 不可训练字段默认排除且开关禁用。
- 至少保留一个训练特征。
- 修改划分或特征集合后，已有成功实验保留为历史结果，不参与新实验的默认模型比较。

### 8.3 模型预处理

模型训练页使用统一的“预处理”模块，模块下包含“缺失值处理”和“标准化”两个分区；两者都属于模型实验配置并随训练结果保存。

#### 8.3.1 缺失值处理

| 字段类型 | 可选方式 |
| --- | --- |
| 数值 | 不处理、均值、中位数、众数、固定值、删除所在行 |
| 类别 | 不处理、保留为缺失类别、众数、固定值、删除所在行 |

| 模型 | 数值默认 | 类别默认 |
| --- | --- | --- |
| 逻辑回归、线性回归 | 均值 | 保留为缺失类别 |
| KNN | 中位数 | 保留为缺失类别 |
| 决策树、随机森林 | 中位数 | 保留为缺失类别 |
| LGBM | 不处理 | 不处理 |

用户可以逐字段修改或批量应用。可能导致训练失败的“不处理”设置显示警告，但不强制阻止选择。

#### 8.3.2 标准化

- 逻辑回归、KNN 和线性回归默认开启。
- 决策树、随机森林和 LGBM 默认关闭。
- 用户可以覆盖默认值；不推荐配置只提示原因。
- 标准化开关使用“对数值特征进行标准化”文案，只作用于数值特征，类别特征不参与标准化。

### 8.4 防止数据泄漏

- 均值、中位数、众数、标准化均值和标准差只根据训练集计算。
- 使用训练集得到的预处理参数转换验证集。
- 删除缺失行时训练集和验证集分别处理。
- 不使用交叉验证；每组参数在训练集训练，并分别计算训练集与验证集指标。
- 验证集指标参与排序和 Top 3 选择，默认按验证集指标排序。
- 模型报告注明“所有预处理参数仅由训练集计算”。

## 9. 模型实验

### 9.1 创建实验

- 点击“新建模型实验”打开模型选择页。
- 每次只创建一个模型实验，不在一个流程中并行放置多个模型。
- 默认名称为“模型名称 + 两位序号”，允许修改。
- 同一数据集内实验名称不得重复。
- 当前数据集没有模型实验时，在实验列表空白区展示“创建模型实验”主按钮；空状态已有主入口时，不在页面标题区重复展示同一入口。

### 9.2 模型范围

| 二分类 / 多分类 | 回归 | 时序预测 |
| --- | --- | --- |
| 逻辑回归 / Softmax | 线性回归 | 基线预测 |
| 决策树分类 | 决策树回归 | 指数平滑 |
| 随机森林分类 | 随机森林回归 | ARIMA |
| KNN 分类 | LGBM 回归 | Prophet |

暂不增加 SVM、XGBoost、神经网络及其他预测算法。

### 9.3 实验状态

- 草稿

- 已完成
- 已取消

### 9.4 实验生命周期

- 草稿、训练失败和已取消实验允许修改并重新训练。

- 需要调整时使用“复制为新模型实验”，名称自动递增。
- 项目、数据集和模型实验均允许删除；删除前二次确认，并级联清理下级对象、保存结果和 API 配置。
- 上游数据划分或特征配置变化后，成功实验保留为历史结果。

## 10. 参数与调参

### 10.1 基础参数

| 模型 | 默认展示参数 |
| --- | --- |
| 逻辑回归 | 正则化强度 `C` |
| 决策树 | 最大深度、最小叶节点样本数 |
| 随机森林 | 树数量、最大深度 |
| KNN | 邻居数量 |
| 线性回归 | 不展示可调参数 |
| LGBM | 树数量、学习率、叶子数 |

默认参数旁提供简短解释和推荐默认值。“高级参数设置”默认折叠，按模型展示真实、适用的可调参数，并提供解释、推荐默认值、范围校验和恢复默认值。枚举参数使用下拉框，例如划分标准、求解器、最大特征数、距离权重和距离度量；下拉框只展示当前模型支持的选项。连续或整数参数使用输入框。参数较少的模型可以不展示高级设置。前端完全不展示随机种子。训练结果记录实际使用的全部参数。

### 10.2 调参方式

可用方式根据模型适用性动态展示：

| 模型 | 快速自动调参 | 网格调参 | 贝叶斯调参 |
| --- | --- | --- | --- |
| LGBM 分类 / 回归 | 支持 | 支持 | 支持 |
| 随机森林分类 / 回归 | 支持 | 支持 | 支持 |
| 决策树分类 / 回归 | 支持 | 支持 | 不展示 |
| KNN 分类 | 支持 | 支持 | 不展示 |
| 逻辑回归 | 支持 | 支持 | 不展示 |
| 普通线性回归 | 不展示 | 不展示 | 不展示 |

不适用的选项直接隐藏，不展示禁用控件。

### 10.3 快速自动调参

- 作为推荐选项，用户无需配置算法或尝试次数。
- 只保留效果最好的三组训练结果。
- 不展示 Optuna、TPE 等技术名称。
- 只展示模拟阶段、进度和结果。
- 页面明确标注“模拟调参”。

### 10.4 网格调参

- 默认使用平台预设候选值，可以直接训练。
- 基础区域只展示最重要的 2 至 3 个调参参数，允许直接增删候选值。
- 用户可展开“更多调参参数”，通过复选框加入其他适用于当前模型的参数；新增参数自动带出可修改的推荐候选值。
- 不展示随机种子或不适用于当前模型的参数。
- 校验空列表、非数字、重复值、允许范围和组合数量。
- 实时显示参数组合数量，并提供“恢复预设值”。
- 组合数为各已启用参数候选值数量的乘积；候选值变化或启用更多参数后实时重新计算。
- 候选值无效时停止计算并提示具体参数；组合数较大时只显示风险提示，不设置强制上限。
- 校验结果直接显示在组合数位置，错误格式为“参数‘参数名’：具体原因”；空值、重复值、非数字、枚举越界或数值越界时，训练前置校验不通过。
- 不允许填写代码或复杂表达式。

### 10.5 贝叶斯调参

- 仅在 LGBM 和随机森林中展示。
- 当前阶段只模拟搜索过程，不执行真实优化。
- 不向初学者暴露算法细节。

## 11. 模拟训练

### 11.1 前置校验

开始训练前检查：

- 项目任务类型有效。
- 数据集、目标列和正类有效。
- 字段检查和特征工程已完成。
- 至少存在一个可训练特征。
- 模型类型与项目任务一致。
- 参数和调参候选值有效。

### 11.2 训练状态

- 校验配置
- 准备数据
- 应用特征工程
- 训练模型或快速自动调参
- 计算指标
- 生成结果

总时长控制在 5–8 秒。用户可以取消；取消后不生成新的模型结果。

训练进度必须使用居中弹窗展示当前阶段、进度条和百分比，不允许退化为页面底部进度条。弹窗不能通过遮罩关闭，支持取消和最小化；“最小化”使用右上角紧凑描边按钮并提示最小化后训练继续，最小化后在右下角展示当前阶段、进度百分比和展开按钮，不展示取消按钮以避免误触。训练完成后自动关闭并进入训练结果，失败时展示原因和返回修改入口。

失败态至少保存 `failed`、`reason` 和当前实验标识。失败弹窗不生成结果；“返回修改”关闭弹窗、恢复实验为可编辑状态并停留在模型训练页。无可训练特征或网格候选值校验失败时使用该失败态承载明确原因。

### 11.3 Mock 原则

- 相同项目、数据集、特征、模型和参数产生稳定结果。
- 所有模拟结果显著标注“模拟结果”或“模拟调参”。
- Mock Service 与 UI 分离，未来可替换为真实 API。

## 12. 训练结果

### 12.1 结果层级

- 使用表格展示，不使用卡片。
- 默认展示综合效果最好的 Top 3，“查看全部结果”展开完整表格。
- 顶部展示项目、数据集、模型实验和模型类型。
- 页面顶部只保留“显示指标”和“对比训练集”两个紧凑控件，不展示数据范围和排序指标下拉框；默认直接展示验证集结果。
- “显示指标”必须按当前任务键分别读写二分类、多分类和回归状态。多分类复用二分类的交互：点击复选项立即更新表格、筛选面板保持展开、至少保留一个指标；取消当前排序指标时自动使用剩余第一项排序。
- 每行提供选择框和“查看模型报告”；查看按钮直接打开该方案报告，不再区分主方案。
- 指标列超出可视宽度时表格横向滚动，“操作”列固定在表格右侧，始终保持可见；训练结果表格的操作列按当前按钮内容自适应宽度，不保留额外的大块空白。
- 指标列使用自动布局：少量指标利用剩余空间，指标较多时按名称和数值内容收缩，最小可读宽度为 104px，达到下限后启用表格内部横向滚动；保存、排名、参数方案和操作等非指标列继续使用各自语义宽度。

### 12.2 分类结果指标

- 可选展示 AUC、KS、F1、准确率、精确率、召回率和“AUC 差值”，默认仅显示 AUC 和 F1，并默认按验证集 AUC 降序。
- “AUC 差值”是过拟合参考项，定义为训练集 AUC − 验证集 AUC，默认不勾选；正值越大表示验证集区分能力相对训练集下降越明显。
- AUC、KS、F1、准确率、精确率和召回率均降序；AUC 差值升序。

### 12.3 回归结果指标

- 可选展示 RMSE、MAE、R²和“RMSE 差值”，默认仅显示 RMSE 和 R²，并默认按验证集 RMSE 升序。
- “RMSE 差值”是过拟合参考项，定义为验证集 RMSE − 训练集 RMSE，并同时显示相对训练集的差距百分比，默认不勾选；正值越大表示验证误差相对训练误差上升越明显。
- RMSE、MAE 和 RMSE 差值升序；R²降序。
- MAE 和 RMSE 不设置通用固定阈值，只与基线或其他实验比较。

### 12.4 指标交互

- “显示指标”支持任意勾选结果表格中的指标列，至少选择一项；分类默认 AUC 和 F1，回归默认 RMSE 和 R²，并提供“恢复默认指标”。勾选后即时生效，面板保持打开，便于连续调整。
- 过拟合参考项放在“显示指标”下拉栏底部并与常规指标做轻量分隔：分类为“AUC 差值”，回归为“RMSE 差值”；两者均默认不勾选，只有用户主动勾选后才在表格中出现，不再固定展示含义不明确的通用差值列。
- 指标表头提供信息图标、简短解释和“越大越好 / 越小越好”；点击已显示的指标表头即可切换排序指标，系统自动确定方向，AUC、KS、F1、准确率、精确率、召回率和 R²降序，RMSE、MAE、AUC 差值及 RMSE 差值升序，不提供手动反转。
- 常规指标排序使用验证集数值；AUC 差值和 RMSE 差值按各自计算结果排序。当前排序表头使用蓝色强调和方向箭头。“对比训练集”只用于在常规指标单元格内增加训练集小字，不增加成倍的指标列，也不改变排序范围。
- 表格下方提供当前任务全部结果指标的说明区，解释指标含义、方向和适用注意事项。
- 点击指标表头切换排序后重新计算排名和 Top 3。
- 默认只勾选当前排序指标下排名第 1 的结果，允许多选，至少保存一组。
- 用户尚未手动选择时，点击表头切换排序指标会自动勾选新排序下第 1 名；用户已手动选择后保留其选择。
- 页面提供“保存所选结果到模型库”按钮，保存后跳转模型库；已保存结果显示“已保存”，避免重复保存。
- 保存时同步写入模型库已保存方案集合，并直接打开当前模型实验的模型库详情，确保新增结果立即可见；详情页头部显示“返回训练结果”，返回后恢复原项目、数据集、实验以及结果页的排序、显示范围和勾选状态。若来源实验被删除，返回该数据集的模型实验列表并提示。
- 训练结果表的“保存”“排名”“参数方案”列分别固定为 56px、60px、150px；前两列居中，参数方案单行省略并通过悬浮提示查看完整参数。必须使用语义类名控制列宽，不依赖 `nth-child`。
- 如果所选结果均已保存，则不重复创建记录，并提示“该结果已保存到模型库”。
- 用户手动修改过结果勾选项后，点击表头切换排序指标必须保留该选择；仅在用户尚未手动选择时自动跟随新的第 1 名。
- Top 3 是同一模型实验下的参数方案，不是三个独立模型。

## 13. 模型报告

模型报告不属于流程步骤，是训练结果的下级详情页。报告页不显示步骤条，底部操作栏左侧提供“返回训练结果”。

- 报告页右上角提供“导出报告”，调用浏览器打印功能，由用户选择“另存为 PDF”；不维护报告保存状态或独立报告中心。
- 模型报告展示保存模型时的训练快照，包括任务、目标列、正类、入模特征数、数据划分、训练时间和模拟结果来源。

### 13.1 二分类报告

- 核心指标：AUC、KS、F1、准确率、精确率和召回率。
- 同时展示训练集指标、验证集指标和两者差值。
- 使用指标对照表逐项展示 AUC、KS、F1、准确率、精确率和召回率的训练集值、验证集值与差值，而不是只对核心单一指标做对照。
- 对照表作为独立的“指标总览”模块展示，包含指标、训练集、验证集、训练 / 验证差值和优化方向；验证集列使用轻量视觉强调，不增加缺乏统一阈值的优劣标签。
- F1 标题旁提供统一信息图标，悬浮说明“精确率与召回率的综合指标，越大越好。”；指标卡片显示“适合同时关注误报和漏报的场景。”
- ROC 曲线、KS 曲线、混淆矩阵和 Gain Table。
- 默认展示验证集混淆矩阵，不额外展示训练集混淆矩阵；矩阵标注当前分类阈值。
- 混淆矩阵展示 TP、TN、FP、FN，并基于矩阵计算准确率、精确率、召回率和 F1；报告展示简短计算公式。
- 指标分母为 0 时显示 `—` 和“当前数据无法计算”，不显示 `NaN` 或无穷值。
- Gain Table 至少展示累计人群比例、累计正类捕获率和 Lift。
- Lift 解释为：“模型筛选效果相对随机筛选提升了多少倍，越大越好。”
- 示例：“Lift = 3，表示命中率约为随机筛选的 3 倍。”

### 13.2 回归报告

- 核心指标：MAE、RMSE 和 R²。
- 同时展示训练集指标、验证集指标和两者差值。
- 使用指标对照表逐项展示 RMSE、MAE 和 R² 的训练集值、验证集值与差值。
- 对照表使用与分类报告一致的“指标总览”布局，RMSE 和 MAE 标记“越小越好”，R² 标记“越大越好”，不增加通用优劣标签。
- 真实值与预测值对比图和残差分布。
- 指标与其他实验或基线的对比提示。

### 13.3 数据概览

- 只统计最终参与训练的特征。
- 数值特征展示样本数、缺失率、均值、中位数、标准差、最小值和最大值。
- 类别特征展示样本数、缺失率和唯一值数量。
- 类别特征不展示众数。

### 13.4 变量重要性

最多展示 Top 10，特征不足时展示全部。已排除和不可训练字段不得出现。

| 模型 | 计算方式 | 页面标注 |
| --- | --- | --- |
| 决策树 | 节点分裂带来的不纯度下降 | 树模型原生重要性：不纯度下降 |
| 随机森林 | 各树不纯度下降重要性的平均值 | 树模型原生重要性：平均不纯度下降 |
| LGBM | 累计分裂增益 | 树模型原生重要性：分裂增益 Gain |
| 逻辑回归、线性回归 | 标准化特征后的模型系数 | 标准化系数，保留正负方向 |
| KNN | 排列重要性 | Permutation Importance |

不同计算方式的分数不可跨模型直接比较。

### 13.5 指标说明

- 指标名称旁提供信息图标和一句简短说明，训练结果、模型报告和项目模型库复用同一份解释。
- 报告增加“指标说明”折叠区，展示完整含义、参考区间和优化方向。
- 分类报告覆盖 AUC、KS、F1、准确率、精确率、召回率、训练 / 验证差值、TP、TN、FP、FN、Lift 和累计正类捕获率；回归报告覆盖 RMSE、MAE、R²、训练 / 验证差值和残差。
- 缺失率和相关系数不增加解释区间。
- 模型报告展示训练集和验证集表现，并注明所有预处理参数仅由训练集计算。

## 14. 模型库与 API 接入配置

### 14.1 模型比较

- 模型库使用“模型列表 → 范围比较详情 → 已保存参数方案”的两级结构。
- 模型列表不在表格上方设置独立筛选区，也不在表头常驻展示筛选框、下拉框或当前筛选状态。“项目、数据集、模型类型”表头常态只显示列名和排序箭头；鼠标停留在整个表头或键盘聚焦排序箭头后展开悬浮筛选面板，当前筛选项仅在面板内部标记，点击选项立即筛选。三个筛选项联动，无效的下级筛选自动恢复为“全部”。
- 模型列表以模型实验为一行，同一实验保存的多个参数方案聚合展示为方案数量，不重复生成模型行。表格展示项目、数据集、模型实验、模型类型、已保存方案数量和创建时间。
- 模型列表默认按最近一次方案保存时间从新到旧排序，不展示指标列，也不展示操作列；项目名称、数据集名称和模型实验名称分别作为三个明确入口，不使用整行点击。
- 项目、数据集、模型实验、模型类型、已保存方案和创建时间六列表头均显示排序箭头并支持升降序切换。首次切换到文本列时默认升序，切换到已保存方案或创建时间时默认降序，再次点击同一箭头反转方向。
- 点击项目名称进入项目级比较，展示当前项目下所有数据集、模型实验、模型类型及全部已保存参数方案，支持同一项目内跨数据集指标比较和排序。
- 项目级比较在存在多个数据集时固定展示纯文字“跨数据集比较风险”提示：不同数据集的样本分布、目标尺度和划分可能不同，指标数值不能直接代表模型优劣；建议优先在同一数据集内比较，并结合业务基线判断。风险提示内不列出数据集，也不提供跳转按钮。
- 项目级比较不设置顶部固定筛选栏；“数据集、模型实验、模型类型”筛选分别集成到对应表头并联动，选择上级范围后无效的下级筛选自动恢复为“全部”。数据集级比较在“模型实验、模型类型”表头提供同样的联动筛选。实验级详情不提供范围筛选。
- 点击数据集名称进入数据集级比较，展示当前项目、当前数据集下所有模型实验、模型类型及全部已保存参数方案。
- 点击模型实验名称进入模型实验级比较，只展示该模型实验下所有已保存参数方案。
- 项目级比较表格中的数据集名称和模型实验名称继续作为明确入口，可分别进入对应的数据集级比较和模型实验级比较；数据集级比较表格中的模型实验名称也可进入该模型实验级比较。
- 从项目详情的“查看本项目模型”进入模型库时显示“返回项目”；从数据检查页的“查看本数据集模型”进入时显示“返回数据集”；从训练结果保存后进入时显示“返回训练结果”。无论当前范围是否已有保存模型，返回入口都必须保留；返回时恢复对应来源页面。从全局模型库进入详情时仍显示“返回模型列表”。
- 模型比较详情的指标和筛选方式与训练结果保持一致：分类默认显示 AUC 和 F1 并按验证集 AUC 降序，回归默认显示 RMSE 和 R²并按验证集 RMSE 升序。
- 详情页保留“显示指标”任意多选、“恢复默认指标”和“对比训练集”；训练集数值显示在同一单元格的验证集数值下方。“显示指标”下拉栏提供默认不勾选的过拟合参考项：分类为 AUC 差值，回归为 RMSE 差值。
- 详情页的范围列、参数方案、创建时间均支持表头升降序；点击已显示的常规指标或过拟合参考项表头时，系统按指标方向自动升序或降序。选择过多指标时表格横向滚动。
- 模型库详情的横向滚动必须发生在表格卡片内部，不得让整个页面产生横向滚动条；右侧操作列继续固定。表头筛选面板展开时在表格内部临时预留空间，避免被滚动容器裁切。
- 模型库指标列与训练结果使用相同的自动宽度和 104px 最小可读宽度规则。
- 模型库指标对比表的项目、数据集、模型实验、模型类型等范围文字保持单行并由内容决定列宽；参数方案保持 150px 语义宽度。操作列按按钮组合的实际宽度展开，按钮及按钮文字必须始终横向排列，不允许换行或纵向堆叠。
- 详情页才展示“操作”列，提供“查看训练结果、查看模型报告、生成 API 配置”，操作列固定在右侧；模型列表首页不出现这些操作。
- 项目级详情表格展示数据集、模型实验和模型类型；数据集级详情展示模型实验和模型类型；模型实验级详情只需展示参数方案。参数方案只显示“网格方案 N”“自动方案 N”或“默认方案”，不直接铺开参数字符串，悬停或键盘聚焦时只展示具体模型参数，不展示预处理配置。
- 保存动作先写入模型库数据再跳转模型列表；新增方案合并进所属模型实验，并更新该模型实验的方案数量和排序时间。
- 新保存结果立即参与项目、数据集、模型类型筛选；进入详情后参与指标排序。
- 历史、需要重新训练和失败结果保留展示，但不参与默认排序。
- 每个详情方案可返回来源实验查看完整训练结果，并提供直接打开该参数方案报告的入口。
- 页面标注“模型指标包含数据预处理方式带来的影响”。
- 模型库没有已保存结果时，在空白区展示操作入口：已有项目时“前往项目训练模型”，没有项目时“创建项目”。

### 14.2 API 接入配置

模型库包含“模型比较”和“API 服务”两个页签。API 不属于训练主流程，只放在模型库的更多操作中。

- 功能名称使用“生成 API 接入配置”，不使用“部署为 API”。
- 仅有效、已完成、已保存的参数方案可以生成。
- 生成时可选择任一已保存方案。
- API 配置绑定具体参数方案。
- 明确标注“模拟 API 接入配置，不可用于真实业务调用”。

API 页面展示：

- API 服务名称、来源项目、数据集、模型实验和参数方案。
- 模拟接口地址和请求方法。
- 输入字段与 JSON 请求示例。
- JavaScript、Python 和 cURL 调用示例及复制按钮。
- 返回字段说明和模拟响应。
- “测试请求”按钮，返回稳定模拟预测结果。
- 更新模型方案和删除 API 配置。

不实现启用 / 停用、API 密钥、权限、调用统计、额度和版本回滚。

- 完成字段类型检查与“不可用于训练”标记。

**验收：** 可以创建分类或回归项目，管理多个数据集并完成数据检查。

### 阶段二：特征准备与预处理

- 移除画布、拖拽、节点、连线和缩放代码。
- 实现固定步骤条和状态流转。
- 实现训练集 / 验证集划分、分类 / 回归差异化特征筛选和训练集指标计算。

**验收：** 用户完成特征准备，所有筛选和预处理参数仅由训练集计算。

### 阶段三：模型实验与调参

- 实现任务类型过滤后的模型选择。
- 实现实验创建、复制、锁定、精简参数和高级参数配置。
- 增加快速自动调参并保留适用的网格、贝叶斯调参。
- 实现训练进度弹窗、最小化和取消。

**验收：** 同一数据集可创建多个模型实验，并完成普通训练或模拟调参。

### 阶段四：结果、模型库与 API

- 实现表格化 Top 3、全部结果、显示指标多选、表头排序、训练集对比和方案保存。

## 18. 测试与验收

### 18.1 核心测试

| 类型 | 范围 |
| --- | --- |
| 单元测试 | CSV 解析、字段类型、时间/频率校验、筛选阈值、配置失效、训练结果排序 |
| 组件测试 | 数据集弹窗、数据预览、步骤条、特征筛选、回测窗口、模型选择、指标帮助、SVG 图表 |
| 集成测试 | 项目到模型报告的分类、回归与单序列时序完整流程 |
| 端到端测试 | 创建项目、上传/示例数据、特征准备、多实验、Top 3、模型库、模拟 API |

### 18.2 关键验收标准

- 项目任务类型在上传数据后不可修改。
- 一个项目可管理多个数据集，一个数据集可创建多个模型实验。
- 项目和数据集卡片均不显示悬浮弹窗；数据集卡片已有信息和操作保持不变。
- 字段类型检查位于数据集模块。
- 自由文本、疑似 ID 和日期字段标注“不可用于训练”。
- 页面不再出现自由画布、拖拽、连线、缩放和平移功能。
- 固定流程使用“数据检查 → 特征准备 → 模型训练 → 训练结果”，模型报告作为结果详情页。
- 回归任务不展示 IV；二分类默认分层划分。
- 特征筛选、填充值和标准化参数只根据训练集计算。
- 自动筛选使用固定推荐规则；“推荐阈值”不改变开关；“确定修改”校验成功后才应用当前数字，回归任务实际应用低方差和目标相关性阈值。
- 平台使用训练集和验证集，不使用测试集与交叉验证；预处理参数只根据训练集计算。
- 分类项目不展示回归模型，回归项目不展示分类模型。
- 快速自动调参不展示算法名称和尝试次数。
- 网格候选值变化后实时重算参数组合数；无效候选值指出具体参数并阻止训练，较大组合只预警、不设硬上限。
- 训练结果使用表格，默认展示 Top 3 和验证集核心指标，可多选显示指标、开启训练集对比、点击表头自动排序并查看对应模型报告；分类 AUC 差值和回归 RMSE 差值位于“显示指标”下拉栏中且默认不展示。
- 分类、回归指标使用正确的排序方向和说明。
- 缺失率和相关系数不展示额外参考区间。
- 变量重要性明确标注计算方式。
- 成功实验锁定；调整时复制为新实验，失败或取消实验允许重新训练。
- 训练弹窗不可通过遮罩关闭，支持最小化和取消；失败时显示原因与“返回修改”，且不生成结果。
- 模型库作为全局一级模块，首页通过项目、数据集和模型类型表头的悬浮面板完成筛选；表头常态只显示列名和排序箭头，不显示固定筛选框或筛选状态。列表按模型实验聚合，六列均支持表头箭头升降序，默认按创建时间从新到旧；首页不展示指标和操作列。
- 点击项目、数据集或模型实验名称分别进入项目级、数据集级或模型实验级比较；项目级详情在数据集、模型实验、模型类型表头筛选，数据集级详情在模型实验、模型类型表头筛选，范围名称继续支持逐层进入。三个范围均使用与训练结果一致的指标多选、训练集对比、表头排序和右侧操作列；项目级跨数据集比较只展示风险文字，不增加数据集按钮。从项目、数据集或训练结果页面进入模型库时必须能返回对应来源页面。
- 模型库保存后立即更新所属模型实验的方案数量和排序时间、阻止重复保存，并可从详情方案直接进入对应模型报告。
- API 接入配置只在模型库中出现，并绑定具体已保存方案。
- 刷新页面后项目、数据集、实验和结果状态可以恢复。
