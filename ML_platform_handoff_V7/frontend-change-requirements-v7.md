# 机器学习平台前端修改需求 V7

本文档完整继承《机器学习平台前端修改需求 V6》的已确认内容，并合并本轮新增的 6 项修改意见。若 V7 与 V6 存在冲突，以 V7 为准；未列出的功能保持现有设计，不增加额外功能。

## 1. 页面导航与流程按钮

- 二级页面按实际去向显示返回按钮，例如“返回项目”“返回训练结果”。
- 首页、项目列表和模型库等一级页面不显示“返回上一步”。
- 所有二级页面统一使用底部吸附操作栏，返回按钮固定在左侧，下一步或主要操作按钮固定在右侧。
- 模型报告等详情页也使用统一的底部操作栏，不再单独把返回按钮放在页面顶部。
- 页面内容较长时，操作栏保持在视口底部，避免用户滚动后找不到返回或下一步按钮；操作栏不得遮挡页面末尾内容。
- 按钮使用具体动作名称，例如“下一步：特征管理”“返回训练结果”。
- 返回时保留用户已经填写的配置和筛选状态。

## 2. 数据集卡片、悬浮弹窗与示例数据

- 项目详情的数据集卡片提供“进入数据集”和“模型实验（数量）”两个明确入口。
- 卡片主体不承担隐含跳转。
- “进入数据集”进入数据检查；“模型实验”进入该数据集的实验列表。
- 数据概览使用统计表，展示前 50 个特征，每页 10 个。
- 统计表展示特征、类型、缺失率，以及适用于该字段类型的统计指标。
- 数据预览只展示带字段表头的原始数据表，最多前 150 行，每页 20 行。
- 数据概览和数据预览两个页签分别分页，并支持横向滚动和固定首列。
- 平台提供分类和回归两套示例数据。
- 在当前任务类型已经明确的项目中，只展示与该任务类型匹配的示例数据。
- 分类和回归示例数据都应增加特征列数量，覆盖数值、类别、缺失值等常见情况，便于测试数据检查、特征准备和模型训练流程。
- 示例数据只用于前端演示和测试，不增加真实数据生成或真实训练能力。

## 3. 特征准备入口

- 从数据检查进入特征准备时，始终先进入训练集 / 验证集划分页面。
- 从特征管理返回时进入划分页面。
- 已选择的划分比例保留，不恢复默认值。
- 刷新或直接打开特征准备页面时可以保留当前内部步骤。

## 4. 自动筛选与阈值设置

- “自动筛选”位于特征管理卡片右上角、筛选栏上方。
- “自动筛选”始终使用系统内置推荐规则，点击后直接更新特征纳入开关。
- 筛选栏保留“推荐阈值”和“确定修改”两个操作。
- “推荐阈值”只把阈值输入框恢复为系统推荐数字，不改变特征纳入开关。
- 用户可以继续修改推荐数字。
- “确定修改”校验并应用用户当前输入的阈值，然后更新特征纳入开关。
- 自动筛选后展示纳入和排除数量。

## 5. 特征筛选指标说明

- 缺失率和特征间相关性不增加解释区间。
- IV、PSI、低方差和目标相关性名称旁增加信息图标。
- 悬浮提示展示指标含义、数值方向和参考范围。
- 筛选栏下方提供“查看指标说明”折叠区。
- IV 说明包含弱、中等、较强以及过高时的数据泄漏风险提示。
- PSI 说明包含稳定、需要关注和分布变化明显三个区间。
- 低方差说明数值较小通常表示特征变化不足。
- 目标相关性说明绝对值越大通常表示线性关系越明显，同时注明接近零不代表一定无用。

## 6. 相关性热力图

- 相关性预警阈值位于热力图区块右上角。
- 阈值修改后必须点击“确定修改”才更新预警结果。
- 未确认的修改显示“尚未应用”。
- 不设置 `0.5` 业务下限，仅校验相关系数有效范围 `0–1`。
- “自动处理高相关特征”使用已经确认的阈值。
- 处理预览根据当前数据集动态生成，不写死字段名称。
- 预览表展示保留字段、排除字段、相关系数和推荐理由。
- 用户确认后才修改纳入开关；被排除字段仍可手动重新纳入。

## 7. 模型参数与高级设置

- 模型训练页面只展示少量常用参数，并在参数旁提供简短解释和推荐默认值。
- 其他参数收纳在“高级参数设置”中，用户展开后可以修改。
- 取值范围固定的枚举参数使用下拉框，不使用自由文本输入，例如决策树的“划分标准”。
- 下拉框展示该模型实际支持的候选项，并明确标注推荐默认值。
- 数值型参数继续使用数字输入框、滑块或候选值编辑控件，不强制改为下拉框。
- 参数控件只展示当前模型适用的内容，不展示不适用的调参选项。

## 8. 网格调参组合数

- 网格候选值区域实时展示需要训练的参数组合数量。
- 组合数等于各已启用参数候选值数量的乘积。
- 增删候选值或启用更多参数后立即重新计算。
- 候选值无效时停止计算并提示具体参数。
- 组合数较大时只显示风险提示，不设置强制上限。
- 快速自动调参不展示组合数量。

## 9. 训练进度

- 训练进度改为居中弹窗，展示阶段、进度条和百分比。
- 训练过程中不能通过遮罩关闭。
- 保留取消训练按钮。
- 弹窗支持最小化为页面右上角的小型进度提示。
- 完成后自动关闭并进入训练结果；失败时展示原因和返回修改入口。

## 10. 实验入口、训练结果与数据划分

- “调参结果”全局改名为“训练结果”，不保留旧名称作为副标题。
- 主流程改为：`数据检查 → 特征准备 → 模型训练 → 训练结果`。
- 已完成实验的列表项或详情区域必须提供明确的“进入训练结果”按钮，用户无需重新进入训练配置流程。
- 未完成实验不展示“进入训练结果”，继续展示与其状态匹配的操作。
- 全平台使用训练集和验证集，不使用测试集和交叉验证。
- 默认划分比例仍为 `80% / 20%`，二分类使用分层划分。
- 缺失值填充、编码和标准化参数只根据训练集计算，再应用到验证集。
- 每组模型参数在训练集训练，并分别计算训练集和验证集指标。
- 训练结果支持按训练集或验证集指标排序，默认按验证集指标排序。
- 分类指标中 AUC、KS、F1、准确率、精确率和召回率降序；训练 / 验证差值升序。
- 回归指标中 RMSE、MAE 升序，R² 降序，训练 / 验证差值升序。
- 切换排序指标后重新计算排名和 Top 3，保留用户已经手动勾选的保存项。
- 快速自动调参只保留效果最好的三组结果。

## 11. 模型报告

- 取消流程中的第五步“模型报告”。
- 模型报告保留为训练结果的下级详情页。
- 训练结果每行提供“查看模型报告”。
- 报告页不显示流程步骤条，并使用统一底部操作栏提供“返回训练结果”。
- 报告同时展示训练集指标、验证集指标和两者差值。
- 分类模型报告增加验证集混淆矩阵，默认不额外展示训练集混淆矩阵。
- 二分类混淆矩阵展示 TP、TN、FP、FN，并按当前分类阈值计算。
- 分类报告展示准确率、精确率、召回率和 F1 等指标，并与混淆矩阵保持一致。
- 指标计算规则如下：准确率 `Accuracy = (TP + TN) / (TP + TN + FP + FN)`；精确率 `Precision = TP / (TP + FP)`；召回率 `Recall = TP / (TP + FN)`；F1 `F1 = 2 × Precision × Recall / (Precision + Recall)`。
- 当指标分母为 `0` 时，前端显示 `—` 并提供“当前数据无法计算”提示，不展示无穷值或 `NaN`。
- 模型库仍可打开对应已保存方案的模型报告。

## 12. 保存到模型库

- 训练结果页允许用户勾选一组或多组参数结果并保存到模型库。
- 点击“保存到模型库”后，必须先把所选结果写入前端模型库数据，再跳转到模型库页面。
- 保存成功后，模型库立即展示新增结果，不能出现跳转后列表为空的情况。
- 同一次实验中保存的多组参数结果，分别形成独立的模型结果记录，但继续归属于同一个实验，不创建新的实验。
- 每条模型结果至少保留所属项目、数据集、实验、模型类型、参数摘要、训练集指标、验证集指标、创建时间和模型报告入口。
- 已经保存的同一结果再次保存时，前端应阻止重复记录并提示“该结果已保存到模型库”。

## 13. 侧边栏与模型库

- 删除侧边栏下方的项目快捷列表，只保留首页、项目、模型库和初学者提示。
- 模型库作为全局一级模块。
- 模型库可以展示全部项目的已保存模型结果。
- 项目筛选增加“全部项目”选项，并作为全局进入模型库时的默认值。
- 数据集筛选随项目筛选联动。
- 从项目或数据集进入模型库时，自动带入对应筛选条件。
- 模型类型筛选继续用于比较同一模型类型的结果。
- 新保存的模型结果进入模型库后，必须参与现有项目、数据集、模型类型筛选和指标排序。

## 14. 范围约束

- 本轮只更新以上已确认的前端设计。
- 不增加真实训练、真实 API、登录权限、云端存储或其他未确认功能。
- 不修改与本轮需求无关的页面结构、视觉样式、字段命名或交互逻辑。
